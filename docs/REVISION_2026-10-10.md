# Held-out year and post-review corrections (2026-10-10)

Response to the three review rounds of 2026-10-10 (overall ≈ 3.5 → 3.5–4.0 boundary).

## 1. Held-out year (lock v1.2, `prereg/PROSPECTIVE_LOCK_v1.2.md`)
* WMT23 en→de / zh→en pools (official mt-metrics-eval MQM), 42 metric variants, the same 15 two-system menus per pair as
  WMT22, pilot 50, ε ∈ {0.01, 0.02}. Strategies S1 (dedup), S2 (dedup + COMET-22 fixed in advance), S3 (dedup + highest pilot
  ρ), S4 (S3 unless ρ < 0.2). `code/mt_build_pool23.py`, `mtme_import23.py`, `RUN_PAIRS_23.sh`, `128_strategies.py`.
* 300 audits (`pair23`), then 2,000 audits (`pair23n`) and boundary stress (`pair23b`, second seed `pair23c`).
* Result (`results/HELDOUT_WMT23.md`): S2 −3.4 % vs S1 (all 26 informative cells), S3 −3.3 %, frozen coefficient +4.2 %;
  S3 vs S2 paired −0.1 % [−0.7, +0.5].

## 2. Corrections made during review
* Known-zero differences zeroed for every evaluator in the audit code (`--zero_known 1`, default). The refitted bound's
  under-coverage at the smallest budgets (0.45–0.50) came from the non-zeroed records; with zeroing it is 0.86–0.89, the
  same as the human-only design (`results/strategies/KNOWN_ZERO_COVERAGE_CHECK.md`, WMT22 re-run `pairmtmez`).
* S2 vs S3 interval: point estimate and interval on the same statistic (mean over cells), one resampling of audit indices
  shared by every cell (common random numbers in `110_unit_audit.py`); decision clusters as sensitivity (`129_s2_vs_s3.py`).
* Decomposition figure (`130_decomposition.py`): the bars stack the means over cells of the per-cell components
  s_D and (1 − s_D)h, which add exactly; medians do not.
* Boundary stress of the strategies: type-I error by budget in labels (budgets are expected Poisson items; 10 items ≈ 110–116
  labels), Monte-Carlo intervals from joint resampling, no pooled binomial test over dependent audits. Cut-offs: the first
  budget from which the observed mean rate stays ≤ 0.10 (55 / 88 items; 206 / 265 labels) or ≤ 0.125 (23 / 29 items),
  reproduced on a second seed; described as observations, not a calibrated bound.
* Restricted protocol (post-hoc sensitivity): no certificate below the cut-off, same rule for every strategy, J50
  interpolated over the allowed budgets only, cell sets fixed to the unrestricted run (`--min_budget`, `--cells_from`).
  On the 26 cells S2's saving is 0.4 % [0.2, 0.6] at the 0.10 cut-off (22 cells certify at the first allowed budget) and
  3.0 % [2.5, 3.4] at 0.125; ranking unchanged.
* The 2-point margin is described as a one-sided check set after the 300-audit results, not a pre-registered equivalence test.
* Wording: "every cell" → the 26 informative cells; the strongest evaluator "cannot be identified in advance" → the tested
  pilot-ρ rule does not find it; the design's J50 saving is estimated, not known in advance; label-cost ordering not
  established; certification is budget-indexed, not a sequential stopping rule; "ceiling" → approximation; the
  design-optimal coefficient is a through-the-origin weighted slope that equals the covariance/variance coefficient only
  for centred predictions; recommendation qualified by the labels a decision needs.
* Manuscript restructured (8-page body), appendix numbering, full-width tables, submission PDF rebuilt (20 pages).
